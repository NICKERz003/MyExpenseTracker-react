# 💰 My Expense Tracker (React.js)

แอปพลิเคชันบันทึกรายรับ-รายจ่ายส่วนตัว พัฒนาด้วย React.js และ Tailwind CSS

### ✨ ฟีเจอร์หลัก

- ✅ บันทึกรายรับ-รายจ่าย พร้อมเลือกวันที่ได้
- ✅ จัดการหมวดหมู่ (เพิ่ม/ลบ) แยกตามประเภทรายรับ-รายจ่าย
- ✅ สรุปผลด้วย Pie Chart พร้อมยอดรวมรายเดือน
- ✅ แสดงรายการแยกตามวันที่ (Group by Date)

### 🛠️ Tech Stack

- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Charts:** Recharts
